
# Functionality: 

### Chat function: 
- Display a chat window for communication between the user and AI agent.
- Provide a text input field for users to enter messages.
- Include a Send button for submitting messages.
- Display user and AI messages as separate chat bubbles.
- Show timestamps for messages.
- Allow users to scroll through previous messages.
- Users can interact with new and existing chats 
- Allow users to copy AI responses.
- Provide buttons for "Retrying" responses from the AI agent 
- Users can pin their important chats on the side bars as well as highlight them based on what their used for. 
### Chat Layout
- Sidebar for conversations or chat history.
- Main area for the active conversation.
- Bottom input area for entering messages.
- AI agent information/settings area.

# Non-functional: 
### Accessibility
- Text should have sufficient contrast against the background.
- Buttons and interactive elements should be easy to identify.
- The interface should support keyboard navigation.
- Font sizes should remain readable across different screen sizes.
